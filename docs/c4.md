## Public API

```js
// content/items/forge.js (plain data)
MATERIALS[id] = { name, tier, dmg, av, value, color, info, bonus?, strReq?, needs? } · MATERIAL_ORDER
FORGED = { armour: ["chain", "scale", "plate", "helm"] } · isForged(kind, id) · materialLine(made)
CLASSES[id] = { name, info?, needs } · CLASS_OF[weaponId] = classId
GEAR_WEAPONS (WEAPONS' shape, tier 0) · GEAR_ARMOURS (ARMOURS' shape, with slot, tier 1-8, info?, bonus?, veil?, wornRep?,
  hourRep?, needs?) · VALUE[id] (copper glim) · TEXT[id] (examine's description)
// an item of the real world: { kind: "weapon" | "armour" | "missile", id, made: <material>, material: <its damage, weapons
//   and missiles>, ench, known, … }; armour's AV + MATERIALS[made].av when forged

// content/items/gear.js
makeGear(kind, id, made = null, extra = {}) → item     // made only where isForged(kind, id)
randomGear(rand, level, luck = 0) → item               // the real world's weapon or armour for a zone of `level`
useful(kind, id) → bool · tierOf(level)
TOOLS[id] = { name, glyph, color, price, info }        // kind "tool": { kind: "tool", effect: id, count }; markerChalk

// content/items/tonics.js
TONICS[id] = { name, value, t, info, use(game, p, k), overdose(game, p), needs? }   // kind "tonic": { kind, effect, count }
injectTonic(game, p, id, rng = Math.random) → { ok, overdose, k, save }   // E on a tonic: one at a time, the TOU save
randomTonic(rand) → { kind: "tonic", effect }          // for loot and stock (balm the commonest)

// content/items/artifacts.js:  ARTIFACTS (12) · ARTIFACTS_WAITING (15 + 3 relics: relic, flat, deep, dark, needs) · CELLS
// content/mutations.js:        MUTATIONS (20) · MUTATIONS_WAITING (20, with needs) · BIBLE_FACTIONS
```

**Surprising / worth knowing:**
- `navigation` is a chance (0.05 is a compass-ring), not points: the map case is 0.03.
- `blinded` does nothing to the player (only ai.js reads it); `darkened` is what shrinks your torch.
- status.js's `catchUpStatuses` lists the statuses before it runs any, so a status added in another's `onEnd` isn't
  advanced by that skip: give the first a `catchUp` (as "tonic:crash" has).
- `progression/chargen.js makeCharacter` puts a kit's weapon straight on `hand_r`: a two-handed one would leave the
  other hand free (request 13).

  `p3i-props`).
