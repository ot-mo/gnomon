## 4. Deviations from the design, with reasons

1. **Combat is d20 (DECISIONS), not §3's dice**: no `penetrations()`, no `pv` key, no dice branch. `RULES.combat` is
   `"legacy"` or `"d20"`; check-combat asserts hit-chance tables and map/3D parity. **`RULES.combat` stays `"legacy"`**
   (the parent game on `main` plays as before); the integrator switches it.
2. Weapons too heavy are still refused at equip time; the −2 to-hit per missing STR point (at most −6) only applies to a
   weapon already held. The Sunder relic still crits ×3 and ignores armour under d20. The AGI crit bonus is rounded to
   whole d20 faces (+2% per point: AGI 20 crits from 19). Under d20 armour can soak a blow to 0 for creatures too,
   except on the Colossus's legs (always 1). Spikes, bombs and status damage use `applyDamage` (no to-hit roll, the old
   flat elite armour). Material bonus reads `item.material`, 0 for now.
3. The ghost rule's torch test is `inDark` everywhere; underground it is exactly the old torch test. Under the sky it
   is a different code path (the legacy temple fixture included; golden still matches). `litMask` uses daylight 1
   until WS3.
4. `creaturesNear` uses buckets only during an update (`buildBuckets`/`dropBuckets`); outside it scans. Creatures keep
   the `state` string and the `bonus` damage field; `c.brain` is made only when needed. The AI skips talkers. A potion
   of seeing shows hostiles only (people show anyway: the floor becomes seen). Spike traps skip talkers and statues.
   Creatures spawned at runtime have `uid: null`. `spawnCreature` doesn't take `opts.faction` yet.
5. **`npcs.js` went whole into `content/legacy/encounters.js`**, not split three ways (§1.4: quests → `story/quests.js`,
   shrines → `social/shrines.js`, `peddlerStock` → `social/merchants.js`, `planEncounters` deleted). The quest machinery
   did go to `story/quests.js`; the rest is the parent's content, moved mechanically, and `planEncounters` is still how
   the legacy stack places its people (it goes when sites plan encounters, WS10). WS6a/WS6b split it further.
6. **Quests live in `game.quests`**, not `game.state.quests` (0D2's codec moves them with the rest of the state). The
   instance has §2.13's fields; `giver`/`target` are null for the legacy quests (their people find them by type). A
   new event, **`"quest:report" { id, quiet }`**, is how a giver says "done" (the dialogue can't know which stage
   handler to call); legacy quests finish on it. The Lich King's quest finishes quietly at the win (the parent set
   `done` without a log line).
7. **Service rows come grouped by service** (all curse-liftings of worn gear, then all enchantings, the forgings,
   identifications, potion namings, curse-liftings in the pack), where the parent interleaved them item by item. The
   rows themselves (label and price) are the same multiset (check-talk, 300 loadouts). The shop's title and its lines
   name the merchant (`PELL'S PACK` as before). `servicesFor` falls back to the type's `merchant.services` (Pell's type
   lists his six), since creatures don't copy a `merchant` component yet.
8. `registerDialogue`'s function gets a third argument `{ first }` (the parent's "you hadn't met"): `talkTo` sets `met`
   before calling it, as the parent did. `bye()` options carry `bye: true`, so registered talk options go in before the
   root's closing goodbyes.
9. **The bot's encounters are driven, not wandered**: it stands the player beside each person (no routing), kills
   Rook's quarry and a shrine's trial with `killMonster` (fights are check-combat's and the smoke run's), and fills in
   Mira's map with `zone.seen`. Everything said goes through real keys (walking into people on the map, E in 3D, digit
   keys, Enter/Tab/Esc in the shop, the lever by walking into it, the skull by stepping on it).
10. The browser smoke is a tool (`tools/browser-0c.mjs`, Playwright, served by `python3 -m http.server`), not a check.
