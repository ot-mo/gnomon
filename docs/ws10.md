## Public API

### Dungeon levels (`gen/dungeon.js`)

```js
generateDungeonLevel(seed, p) → Zone   // p as P0, every part now read:
//   theme          DUNGEON_THEMES id: "legacy" (the parent's) and content/dungeons.js's deepwright, lair, salt, glass,
//                  shade, gears, rust, wax, paper, horn
//   gimmicks       GIMMICKS ids, run after the loot in the order given (an unknown id throws)
//   bottom         on the last level (gen/vaults.js bottomHall):
//                    { kind: "guardian", id }                 flatqueen | warden | colossus; no stairs behind the gate
//                    { kind: "boss", id }                     the Lich's throne (the legacy stack)
//                    { kind: "legend", id, uid, hall, legend: LegendDef }   a lair hall with its owner (throws
//                                                             without the def)
//                    { kind: "relic", id, relic: RelicDef | null, trueMarks: [n…] }   an Hour site's reliquary
//   creatureTable  type ids (their own depths and weights) or a region's [type, weight, lo, hi] rows; null: legacy
//   holesIn        { x0, y0, x1, y1 } | null: random holes only in rooms inside it (a vault's chasms are its puzzle)
//   cradle         true: a Truing Cradle (B.STATION, two blocks) in a corner of some room (zone.cradle)
//   murals         [{ text, map }]: the murals gimmick's accounts
validateDungeonLevel(zone, p)          // + "legend missing or unreachable", "the reliquary's altar missing or unreachable"
GIMMICKS = { flooded, lightless, flatland, allDeep, haunted, spikeworks, oneBeat, collapsed, murals, braziers }
//   (zone, rng, rooms, p, ctx) => void; ctx = { start, nearDoor, holesOk, depth, final, cosmetic }. lightless and
//   oneBeat hold level-wide over whatever ran after them. Each keeps validateDungeonLevel passing, and each gives
//   both views something (the header of the GIMMICKS section in the file says what).
BOTTOM_LOOT            // re-exported from gen/vaults.js (below)
// Zone fields a site level may carry (plain JSON, saved as they are): bottomLoot { trueMarks, relic, bodyMod, legend },
// murals [{ x, y, z, view: "3d" | "map", text }], beat { period, phase } (oneBeat), cradle { x, y }, liquid "brine".
```

### Halls and parts (`gen/vaults.js`)

```js
LAIR_HALLS = { plain, beat, herd, braziers }   // ids "lair:<hall>"; N the legend, A its loot on an altar, H its herd,
                                               // ^ its ring of spikes on one beat, f braziers (no lamps in that hall)
RELIC_HALLS = { reliquary }                    // A the relic on an altar, M a pile of true-marks per number, O an artifact,
                                               // the Hour's likeness in gold mosaic (read from above)
bottomHall(bottom) → vault | null              // pickVault uses it on a last level
spawnLegend(zone, def, x, y, z, rng) → c       // the species at def.level, ×2 HP, ×10 XP, named, uid, flags.legend,
                                               // brain.hook "legend:<hook>", legendLooks
BOTTOM_LOOT = { trueMark(count) → item | null, // { kind: "credit", count } while WS5's kind is registered, else null
                bodyMod: null | (rng, level) → item,   // WS5's randomBodyMod (integration request 3)
                relic(def, rng) → item }       // the history relic's base item with histRelic, relicName, uid, relicSpawn
// Legend letters: legend, herd, bottomLoot, trueMark, bodyMod, cradle (C1's plans can use "cradle" for the Truing
// Cradles at Benchmark, the Metronome and the Square). Vaults with chasms carry `holes: true` and aren't drawn on a
// last level.
```

### Sites (`world/sites.js`)

```js
placeSites(run) → run          // landmarks; history's site requests first (kind "historic", runRng(run, "historic"));
                               // then villages, ruins, lairs, stations by region chance on P0's stream (P0's draws)
dungeonParams(run, site, z)    // + bottom with its LegendDef / RelicDef, vaultPool by level, the region's creatures,
                               // cradle, murals, floorGimmicks, named floors
SITE_KINDS = ["village", "ruin", "lair", "historic", "station"]
SITE_SHAPES                    // + historic 14×10, station 10×8 (no dungeon)
makeLegend(rng, site, bottomLevel) → LegendDef    // bible §12.13: bottom level + 3, a template, 0-2 mutations, 1-3 opinions
placeLegends(run) → Map<uid, LegendDef>           // what run.legends should hold (integration request 2)
legendOf(run, uid) → LegendDef | null
// SITE_BUILDERS registered here: ruin, lair, historic, station, dungeon (village stays WS7's). Each marks its walls in
// the surface's plan mask, so the surface's checks count them as planned.
// Site (new fields): historyRef { rulerId, eventId, requestId, relicId }, legend (a lair's LegendDef), toppled (a ruin).
// DungeonSpec (new fields): floorGimmicks [[id]…] per floor, named, murals, cradle [z], bottom.uid / hall / trueMarks.
```
